## Project Title

### Develop a Responsive Student Registration and Result Management System using HTML5, CSS3 and JavaScript

---

## Project Brief Description

The **Student Registration and Result Management System** is a responsive web application developed using **HTML5, CSS3, and JavaScript**.

The application allows students to enter their personal details and subject-wise marks. JavaScript is used to validate the entered data, calculate the total marks and percentage, and determine whether the student has **Passed or Failed**.

The result is dynamically displayed on the webpage without reloading the page. The student information is converted into **JSON format** and stored in the browser's **Local Storage**, allowing the data to be maintained locally.

---

## Technologies Used

- **HTML5** – Structure and form elements
- **CSS3** – Responsive design and styling
- **JavaScript** – Validation, calculations, DOM manipulation and Local Storage

---

## Key Features

- Student registration form
- Student details validation
- Subject-wise marks input
- Total marks calculation
- Percentage calculation
- Pass/Fail result determination
- Dynamic result display
- Student object converted into JSON
- Data stored using Local Storage
- Responsive user interface

## Project Outcome

This project demonstrates the practical use of **HTML5, CSS3, and JavaScript** to develop a responsive and interactive student management application with client-side validation, dynamic DOM manipulation, JSON handling, and browser Local Storage.
