## Assignment-01 – Student Registration and Result Management System

### Brief Description

**Assignment-01** focuses on developing a responsive **Student Registration and Result Management System** using **HTML5, CSS3 and JavaScript**.

The application allows students to enter their personal details and subject-wise marks. JavaScript validates the data, calculates total marks and percentage, determines the **Pass/Fail** result, and dynamically displays the result without reloading the page.

The project also demonstrates **JSON handling and Local Storage** for storing student information in the browser.

### Key Concepts Demonstrated

* HTML5 form development
* CSS3 responsive design
* JavaScript form validation
* DOM manipulation
* Total and percentage calculation
* Pass/Fail logic
* JSON object handling
* Browser Local Storage
* Dynamic result display
