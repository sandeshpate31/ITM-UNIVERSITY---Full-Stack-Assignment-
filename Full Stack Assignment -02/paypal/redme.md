## How to Run the Project

1. Install Node.js.
2. Open the terminal inside the `paypal` folder.
3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

   If the project uses Create React App instead of Vite, use `npm start`.

5. Open the local URL displayed in the terminal.
